# Development setup

## Prerequisites

- Windows 10/11 x64 (the daemon's terminal backend is Windows-only; the portable packages also test on Linux).
- WebView2 Evergreen runtime (preinstalled on Windows 11). Check: `orole daemon diagnostics` prints `webview2:`.
- Go: the `go` line in `go.mod` (currently 1.27.1). A older local Go auto-downloads the toolchain.
- [Bun](https://bun.sh) for the frontend. Git. PowerShell 5.1+ for `scripts/*.ps1`. GNU make is optional: every
  `Makefile` target is a thin wrapper over a documented command.
- NSIS is **not** needed: `mygo build` downloads NSIS 3.13 on first use into `%LOCALAPPDATA%\mygo`.

## First run

```powershell
git clone https://github.com/rayorole/orole-os-desktop ; cd orole-os-desktop
bun install --cwd frontend
$env:OROLE_HOME = "$PWD\profiles\dev"   # isolate dev data (.\start.ps1 does this); see resetting-dev-data.md
go tool mygo dev                         # builds build\orole-daemon.exe, starts Vite on :5173, opens the app
```

`mygo.json` `devCommand` is `go build -o build/orole-daemon.exe ./cmd/daemon && bun run --cwd frontend dev`.
The app launches the daemon itself (`control.Ensure`); you do not start it by hand.

Other entry points:

| Task | Command |
|---|---|
| Browser-only UI preview (no daemon; preview mode) | `bun run --cwd frontend dev` -> http://localhost:5173 |
| Daemon in the foreground with logs | `go run ./cmd/daemon -stderr -v` |
| CLI without building | `go run ./cmd/orole-cli daemon status` |
| After changing a bound service/event in `internal/app` | `go tool mygo generate` and commit `frontend/src/mygo.ts` |
| Build everything | `./scripts/build.ps1` (see `packaging.md`) |

## Repository layout

`cmd/{desktop,daemon,orole-cli}`, `internal/*`, `migrations/`, `frontend/`, `scripts/`, `tests/performance/`,
`docs/`, `resources/icon.png` (generated by `go run ./scripts/genicon`), `mygo.json`.

## Conventions

See `AGENTS.md`: conventional lowercase commits, branch `feat/<issue>-<slug>`, `Closes #N`, docs in the same PR,
`go fmt`, `go vet`, `go test -race`.
